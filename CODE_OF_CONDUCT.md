# Código de conducta del proyecto

## Nuestro compromiso

Nos comprometemos a mantener un ambiente respetuoso y libre de acoso para
todos, sin importar la edad, el cuerpo, la procedencia, la identidad, la
orientación, la capacidad, el aspecto físico, la raza, la religión, la
identidad o el género, la orientación sexual, el nivel de experiencia, el
nivel de educación, el estado socioeconómico o cualquier otra representación
personal.

## Comportamiento esperado

- Usar un lenguaje amable y aceptable.
- Respetar las opiniones y puntos de vista distintos.
- Aceptar la crítica constructiva con elegancia.
- Centrarse en lo que es mejor para la comunidad.
- Mostrar empatía hacia los demás.

## Comportamiento inaceptable

- El uso de lenguaje o imágenes sexualizadas y no deseadas.
- Comentarios ofensivos, insultos o ataques personales.
- Acoso público o privado.
- Publicar información privada de terceros sin su consentimiento explícito.
- Otras conductas que puedan considerarse inapropiadas en un entorno
  profesional.

## Alcance

Este código de conducta se aplica en todos los espacios del proyecto
(repositorios, issues, discussions y pull requests) y cuando un individuo
representa oficialmente al proyecto en espacios públicos.

## Aplicación

Las infracciones se reportan de forma privada a los mantenedores del
repositorio mediante el reporte privado de seguridad de GitHub. Todos los
reportes se revisarán de forma confidencial y se investigarán de manera
apropiada.

## Atribución

Este código de conducta está adaptado del
[Contributor Covenant](https://www.contributor-covenant.org), versión 2.1.
